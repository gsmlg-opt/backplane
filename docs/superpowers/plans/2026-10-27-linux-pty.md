# Linux PTY implementation plan

Approved design: `docs/superpowers/specs/2026-10-27-linux-pty-design.md` (#115).
Baseline: main `d153846a`; preserve #118 Procfs and concurrent runtime/AI work.

1. Write failing native protocol tests for actual capability probes, READY/ACK
   dispatch gate, dimensions/controlling terminal, bytes, cancellation, job-control
   groups and lost-helper proof. Compile with C11 `-Wall -Wextra -Werror`.
2. Implement bounded packet4 broker/guardian. Guardian pins the session leader,
   validates procfs identity around pidfd acquisition, performs TERM/CONT then
   thread-stop census/KILL with bounded observed convergence, and reports exact
   evidence. Broker reaps guardian before final proof. Missing proof stays uncertain.
3. Write failing LocalCommand/public Codex tests. Add private Pty transport,
   explicit startup probe/opt-in capabilities and per-invocation selection. Route
   helper proof plus broker exit through existing settlement; preserve pipe
   callbacks, retention, reservations, receipts and owner fencing. Project UTF-8
   incrementally with deterministic replacement and hard-cap accounting.
4. Package C source with explicit `mix backplane.pty.build`; normal compile stays
   compiler-free. Exclude generated binaries from Hex. Add isolated consumer and
   native build steps to runtime CI/Linux release/Docker; update contract tests.
5. Run focused native/runtime/pipe tests, strict compile/format and extracted-source
   consumer. Native amd64/arm64 verification remains separate evidence; do not
   claim an unavailable host. Review integrated diff and provide parent-owned doc
   snippets, actual evidence and remaining limits. No Git mutations or services.

Every shared BEAM/Mix/devenv command uses `flock /tmp/backplane-ir43-beam.lock`
and `ERL_FLAGS='+S 4:4'`. Native tests build only task-owned helper artifacts.
Sol repair rounds start at 0; initial implementation is not a repair round.
