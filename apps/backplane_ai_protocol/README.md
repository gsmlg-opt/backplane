# Backplane.AiProtocol

`backplane_ai_protocol` is a standalone production package for provider-neutral AI protocol contracts.

This skeleton intentionally contains no provider transport, credential handling, database, Phoenix, Backplane, or network startup behavior. Its API will be frozen by W1.2 and later work packages.
