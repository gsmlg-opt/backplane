# Backplane.AiProtocol.TestKit

`backplane_ai_protocol_testkit` is a separately consumable support package for testing the AI protocol foundation.

It may depend on `backplane_ai_protocol`, but `backplane_ai_protocol` must never depend on this package. The current skeleton establishes that dependency direction only; reusable protocol fixtures and fault servers arrive with later work packages.
