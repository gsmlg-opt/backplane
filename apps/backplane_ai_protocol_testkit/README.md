# Backplane.AiProtocol.TestKit

`backplane_ai_protocol_testkit` is a separately consumable support package for testing the AI protocol foundation.

It may depend on `backplane_ai_protocol`, but `backplane_ai_protocol` must never depend on this package. It currently ships deterministic OpenAI Responses raw fixtures for the first Backplane consumer slice. It is test support and must not enter production releases.
